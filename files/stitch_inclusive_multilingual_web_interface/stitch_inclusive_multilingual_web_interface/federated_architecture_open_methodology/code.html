ADR-001

Self-Hosted Kafka (Strimzi Operator) over Managed Hyperscaler Cloud

Decision: ACCEPTED Portability Target

Context

Global cloud providers offer managed queues (AWS SQS, Google PubSub). However, relying on proprietary cloud backplanes violates Digital Public Good standard #6 (freedom from cloud lock-in) and prevents bare-metal deployment in state-run datacenters.

Decision Rationale

Standardize on the CNCF-backed Strimzi Apache Kafka Operator across vanilla Kubernetes clusters. Enables air-gapped sovereign execution with standard Helm charts, guaranteed throughput of 40,000 evt/s, and full data-plane independence.

Consequences

Requires operational competence in persistent volume orchestration and ZooKeeper/KRaft quorum management. Mitigated via automated GitOps reconciliation (ArgoCD) and bundled Prometheus/Grafana runbooks.

ADR-002

Server-Side Hybrid Batch Whisper & NLLB-200 for Low-Power Telephony

Decision: ACCEPTED Hardware Inclusivity

Context

Client-side ASR (WebSpeech or quantized ONNX models) drains device battery on $40 Android devices and fails on standard feature-phone audio recorded via GSM telephony 8kHz sampling.

Decision Rationale

Implement server-side asynchronous batch processing using Open-Weight Whisper Medium fine-tuned on local dialect corpuses, piped into Meta NLLB-200. Audio is compressed via libopus before transit, cutting data usage to <20KB per report.

Consequences

Requires dedicated GPU (NVIDIA A10G or open ROCm) worker pools inside the national k8s boundary. Solved by dynamic horizontal autoscaling: queues back up safely in Kafka during peak daytime spikes.

ADR-003

Federated Sovereign Data Plane with Zero Cross-Border Flow

Decision: ACCEPTED Legal & Sovereignty

Context

BRICS intergovernmental conventions prohibit civic complaints, geographic coordinates, or demographic telemetry from traversing foreign network borders or consolidating in centralized overseas repositories.

Decision Rationale

Establish fully autonomous, isolated k8s clusters per nation. Cross-nation federation exchanges purely non-sensitive, aggregated metrics (e.g., Model weights via Differential Privacy, SDG achievement indices) over mTLS APIs.

Consequences

Eliminates the possibility of cross-border subpoena or foreign surveillance. Requires each nation to provide tier-3 datacenter hosting or sovereign state cloud environments with physical jurisdiction.
